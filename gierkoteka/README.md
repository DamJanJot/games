# Gierkoteka

Statyczny katalog prostych gier logicznych.

## Gry

- `index.html` - lista gier w kafelkach.
- `solitaire.html` - klasyczny pasjans.
- `arrows.html` - kolorowe strzalki.
- `sudoku.html` - mini sudoku 4x4.

## Uruchomienie

Otworz `index.html` w przegladarce albo wrzuc folder na serwer statyczny.
